Expense Tracker (Трекер расходов)

**Автор:** [Артем Порхалев]

Описание программы
Простое десктопное приложение на Python для контроля личных финансов. Позволяет записывать траты, классифицировать их по категориям и анализировать общую сумму за все время или по конкретным фильтрам.

Функционал
- Добавление расходов (сумма, категория, дата).
- Автоматическая проверка корректности ввода (валидация данных).
- Фильтрация записей по категориям.
- Автоматический подсчет итоговой суммы отображаемых расходов.
- Сохранение данных в формате JSON (данные не пропадают при закрытии).

Как использовать
1. Установите Python 3.x.
2. Запустите программу: `python main.py`.
3. Введите сумму расхода, выберите категорию и дату.
4. Нажмите «Добавить расход». Данные появятся в таблице ниже.
5. Используйте выпадающий список фильтра для просмотра конкретных трат.

Примеры тестов
1. **Проверка суммы:** Попробуйте ввести "-100" или "текст" в поле суммы. Программа выдаст предупреждение.
2. **Проверка даты:** Введите дату в формате "30.12.2023" вместо "2023-12-30". Программа попросит исправить формат.
3. **Сохранение:** Добавьте расход, закройте программу и откройте снова — данные останутся на месте.
